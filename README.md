# Abhirup Das — Personal Portfolio

A responsive portfolio website for **Abhirup Das**, Intelligent Automation, Python & GenAI Developer.

## Files
- `index.html` — website content and structure
- `styles.css` — responsive styling
- `script.js` — navigation and scroll interactions
- `assets/profile.png` — supplied profile photograph
- `assets/Abhirup_Das_Resume.pdf` — downloadable résumé

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## GitHub Pages
In repository Settings → Pages, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.

The intended website address is `https://AbhirupDas-0509.github.io/`.

No project showcase or private repository links are included.
